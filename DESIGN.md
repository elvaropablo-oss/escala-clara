# Design direction

**North star:** an architectural studio cover sheet: pale stone paper, disciplined navy rules, a single rust-red pencil annotation and generous working space.

Large, light-weight typography carries the hierarchy. Vertical scale ratios anchor each hero. Tool directories use stepped drafting sheets, while forms and results preserve thin technical rules and explicit units. The palette is stone `#eeeae0`, paper `#f9f7f1`, navy `#10283b`, rust `#e05f3f` and pale drafting green `#d9e9e5`.

The system uses square corners, no soft shadows and restrained motion. At 840 px, layouts become one column and ratios rotate into a horizontal caption. Focus uses a 3 px rust outline; print removes navigation and decorative ratios while preserving calculations.
