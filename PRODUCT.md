# EscalaClara

EscalaClara converts linear scale relationships for plans, maps and models. It helps users move between drawing and reality, discover the scale of a copy and calculate a print percentage while keeping units and assumptions visible.

The main journeys are plan-to-reality conversion, unknown-scale detection and print rescaling. Calculations remain local, use millimetres internally and must remind users that written dimensions take precedence over ruler measurements. The interface must remain usable on a phone beside a drawing and printable for reference.
